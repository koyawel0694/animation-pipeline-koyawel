# Character reference policy

## Canonical source

Chapter 0 is the canonical reference chapter for the series cast.

## Deferred change

The currently stored Chapter 0 character sheets were generated as provisional 2D references before the final series look was selected. They must not be treated as the final live-action identity anchors.

## One-time regeneration

After the final art/animation style is approved:

1. Regenerate every recurring Chapter 0 character reference once in that approved style.
2. Validate identity, face, hair, body proportions, wardrobe, props, palette, and creature scale.
3. Mark the new Chapter 0 reference directory as canonical.
4. Reuse those exact files for every later chapter through the series finale.
5. Record the source directory in each later chapter’s `character_refs_source.json`.

Do not regenerate a recurring character independently for each chapter. That causes face, costume, age, and silhouette drift.

## Live-action exception

For `photorealistic_live_action`, create a dedicated live-action reference set. Translate the 2D design into casting, wardrobe, props, production design, practical effects, creature/CGI integration, and photographed lighting. Do not use a 2D “not photorealistic” style lock together with the live-action preset.
