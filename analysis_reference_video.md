### Script Pattern

2. SETUP (5-15s):  Character intro + premise
3. CONFLICT (15-30s): Rising tension, stakes established
4. CLIMAX (30-45s): Action beats, key moments
5. VERDICT (45-55s): Rating/score + key themes
6. CTA (55-58s):   "Subscribe for MORE" (audio + visual word "MORE")

### Script Style
- Short, punchy sentences (1-3 sentences per beat)
- Emphasis words shown as single subtitle
- Dramatic, concise narration
- No filler words — every word earns its place
- ~58 seconds = ~175 words at natural pace
